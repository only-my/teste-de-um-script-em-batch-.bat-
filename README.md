# teste-de-um-script-em-batch-.bat-
script basico n completo q busca instalar roms (stock ou custom) para o moto g34 5g (fogos) 

nao recomendo usar em outros dispostivos por que tem tipo uma "ordem" certa de instalação

atualização:

Fiz o bloqueio de oem em meu dispositivo, o script ficara sem atualizações por tempo indeterminado.


#fim.


A algumas semanas meu dispositivo começou a apresentar falhas: o Wi-Fi parou de funcionar, reiniciava sozinho e isso me impediu de testar e finalizar o arquivo. Mais recentemente, ele deixou de dar boot nas ROMs (stock e custom). Como troquei de aparelho, não vejo motivo para continuar o projeto.

Esse upload mais recente é a última versão que fiz. O projeto sempre foi pessoal, nada grande, apenas um utilitário que criei para facilitar meus próprios testes. Mesmo assim, cada linha escrita foi parte do meu aprendizado e da minha caminhada.

obs: como nao uso a muito tempo, ele pode ter varios bugs presentes..
